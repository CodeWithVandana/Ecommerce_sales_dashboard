### 📊 Madhav Ecommerce Sales Dashboard – Power BI Project

This interactive Power BI dashboard provides a complete overview of ecommerce sales performance across multiple dimensions such as state, category, 
customer, payment modes, and monthly profit trends. It helps identify key revenue drivers, high-performing regions, and customer buying behavior.

## Key Insights Included
  -Total Sales, Profit, Quantity, and AOV KPIs
  -Sales by State to highlight top-performing regions
  -Quantity by Category (Donut Chart) showing product demand distribution
  -Profit by Month with positive vs negative profit visualization
  -Customer-wise Sales Contribution
  -Payment Mode Analysis to understand customer preferences
  -Sub-Category Profit Breakdown to identify best-selling products
